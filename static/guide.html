Start here

Load a model

Drop an .mps or .lp file onto the home page, or choose a file. Gzipped files work too. Use “try a random instance” to explore without a file.

Instance Bank and search

Search instance names in the header, or browse the Instance Bank. Press S on the main page to focus instance search. Available actions depend on the loaded model.

Guided tour

Choose “take a tour” on the home page or “Tour” after loading a model. The tour changes to explain the current view. Press T on the main page to start it.

Read a model

Variable colors and hover details

In constraint expressions, binary variables use blue, declared integers green, continuous variables orange, and certified implied integers cyan. Hover a variable for its original name, bounds, type, objective coefficient, and available LP value. Hovering also highlights its other occurrences.

Implied integer variables

A continuous variable is marked implied integer when an equality with otherwise declared integer or binary variables proves it integer-valued: dividing by its coefficient must leave an integer RHS and integer coefficients. For example, 2y + 4x = 6 implies integer y if x is integer. This basic check does not chain deductions or change the declared variable type.

Constraint tags

Click “tags N” beside a constraint to reveal its classifications; click “hide tags” to collapse them. “All integer” includes binary, integer, and certified implied-integer variables. “Variable bound” requires a one-sided inequality with one binary and one continuous or integer variable. See the constraint definitions for every tag.

Variable bars, sorting, and compression

Open Variables to compare bounds on a shared number line. Arrows indicate infinite bounds; bar thickness reflects objective magnitude. Use the sort buttons to reorder variables; click again to reverse. “compress” groups variables with the same type, bounds, and objective coefficient; click a group to expand it.

Objective groups and math mode

Open Objective to inspect its terms. Click a compressed Σ group to expand the individual variables. The math toggle switches expressions to mathematical typesetting.

Coefficient ranges and sparsity

Coefficient ranges summarize the sizes of matrix, objective, bound, and RHS values. Open Sparsity Pattern to see nonzero locations and connected components. Component selection filters the model view; the enlarged sparsity view supports zooming and panning.

Filter and navigate

Filter constraints

Click a constraint-type tag in the summary to filter by that type. Click a variable name to select constraints containing it. Use the constraint name field or the nz bound to narrow the list further. Active filters appear above the model statistics; × removes a condition and “Clear all” resets the filters.

AND / OR groups

Click filter chips to select them, or drag a rectangle across chips to group them. Click the AND or OR buttons to switch the operator. Select existing groups to form a nested group. The group’s × removes the grouping.

NOT filters

Right-click a filter chip to toggle NOT. Right-click a group’s background to negate the entire group, such as NOT (A OR B). An explicit NOT label and dashed border mark negation. Right-click again to restore the original condition.

Follow a constraint’s variables

Click a constraint name or its funnel button to inspect its variables and related constraints. This is useful for following a small part of a large model.

Solve and simplify

Solver selection and parameters

Choose SCIP or HiGHS in the model toolbar. Open the settings button beside the solver picker to edit its parameters; the popover links to the solver documentation. Solving runs in the browser via WebAssembly.

Presolve

Click Presolve to simplify the model and update its displayed statistics and expressions. Depending on the selected solver, additional information such as cliques, implications, or symmetry becomes available.

Solve LP and Solve MIP

Solve LP computes the continuous relaxation; available solution values appear in hover details and on variable bars. Fractional values of declared integer variables are highlighted. Solve MIP solves with the declared integrality restrictions.

Solve a subset of constraints

Use the ▶ button beside a constraint to compare its LP and MIP solutions in isolation. “Solve visible LP” solves the LP using the currently visible constraint subset. These results describe that subset, rather than the full model.

Explore further

Matrix and conflict graph

Use Matrix in the model toolbar for a detailed matrix view and presolve visualization. Conflict Graph opens a graph view of binary conflicts. These links appear when available for the loaded instance.

Constraint aggregation

Click a constraint side or bound to add it to the aggregation playground, or use “Aggregate visible” for the filtered list. Adjust multipliers and inspect the resulting inequality. The playground also offers variable substitutions and CG or MIR rounding when their conditions are met.

Lagrangian plots

Use “Plot all visible L(λ)” in the Constraints toolbar to explore Lagrangian plots for the current constraint selection. Start with a small filtered subset to keep the plot manageable.

Benchmarks

Open Benchmarks to browse published solver comparisons, versions, and per-instance results. The model toolbar links to instance benchmark information when available.
